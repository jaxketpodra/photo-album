📷 相册传照片教程

一共 3 步，大约 3 分钟。以后每次传照片都照这个来。

1把照片传上去

打开相册仓库：github.com/jaxketpodra/photo-album（需要先登录你的 GitHub 账号）

  • 点 images 文件夹进去
  • 点页面右上角的 Add file → 选 Upload files
  • 把照片文件直接拖进页面里（可以一次拖很多张）
  • 往下滚，点绿色按钮 Commit changes → 再点一次确认
✅ 照片要求：JPG 或 PNG 格式，单张别超过 3MB。文件名建议用 01.jpg、02.jpg 这种——别用中文和空格，容易出错。

2告诉相册"我加了照片"

回到仓库主页，点 photos.json 这个文件 → 点右上角的 ✏️ 铅笔图标（Edit）

在 photos 那一列里，复制一行，改三个地方，粘贴到列表末尾：

{ "src": "images/01.jpg", "title": "照片标题", "caption": "想说的话" },
  • images/01.jpg → 改成你刚传的文件名（和第一步的文件名一模一样）
  • 照片标题 → 这张照片叫什么（随便写）
  • 想说的话 → 一句话说明（可以不写，留空也行）

改完往下滚，点绿色按钮 Commit changes。

⚠️ 标点符号要用英文的（" 和 , ），别用中文的（" 和 ，）。删掉不想留的照片，就把对应那一整行删掉。

3看效果

等大约 1 分钟（页面自动更新），然后打开相册：

jaxketpodra.github.io/photo-album/

照片就出现在墙上了！顺序 = 你在 photos.json 里的行顺序，想排前面就放上面。
